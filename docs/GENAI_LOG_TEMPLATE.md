Recommended evidence for each entry:

1. Exact prompt text.
2. Exact generated answer/code or a link/screenshot permitted by the course.
3. Human refinement: what the team changed after the generated result.
4. Verification: build/test/demo used to validate the final code.
5. Git commit that contains the accepted change.

The final report should distinguish team-authored design decisions from GenAI-assisted suggestions.
