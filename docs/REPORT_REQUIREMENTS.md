# Report Requirements Checklist

Keep the report numbered exactly as required by the course instructions.

1. **Sequence diagram** — show the main TCP control and UDP data-transfer sequence, including Active/PASV setup and RDT acknowledgements.
2. **Data structures** — explain packet/header fields, session state, DataChannel configuration, transfer metadata and sliding-window state.
3. **Flowcharts** — include the important client/server command flow and reliable transfer/retransmission flow.
4. **Assignment matrix** — list each member, modules/features, contribution percentage and Git evidence.
5. **Self/peer evaluation** — use accurate individual evaluations consistent with actual work.
6. **GenAI usage log** — include exact prompts/raw outputs/refinement evidence according to the course policy. See `GENAI_LOG_TEMPLATE.md`.
7. **Demo evidence** — screenshots/logs proving clean build, upload/download, Active/PASV, RDT recovery, SHA-256, ABOR and concurrent sessions.

Before submission, confirm that the contribution matrix, Git history, oral-defense ownership and report all tell the same story.
